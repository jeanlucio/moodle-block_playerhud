# 📖 Usage

1. Add the **PlayerHUD Block** to your course.
2. Access the **Management Panel** (Teacher role required).
3. Choose how to set it up:
   * **Quick start:** run the **Gamification Wizard** to auto-generate items, quests, ranking, and other mechanics in one pass (see [Features](features.html) above).
   * **Manual setup:** configure each mechanic yourself:
     * Items
     * XP values
     * Number of levels
     * XP thresholds
     * Drop placements
     * Recharge time (Cooldown)
     * Collection limits
4. Students collect items directly within course sections.
5. XP, levels, and ranking update automatically.

**Removing the block** from a course deletes the whole game and every student's progress at once, and it cannot be undone from the block. Back up the course with user data first, or use **Hide** in the block menu to take the game out of sight without losing anything. The teacher manual (the **?** button of the management panel) explains this under *Removing the block*.
